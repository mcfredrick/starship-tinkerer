# Walk-in customers from the job board. "guest" is whoever this is; {guest}, {guest_ship} and
# {request} fill in their name, ship and what they asked for. Arrivals vary by their first trait,
# reactions by tier, with trait-specific reactions where the trait would change things.

== walkin_arrives
* The {guest_ship} eases into the bay, and its owner climbs down.
guest: Hello. I'm {guest}. I saw your notice on the board.
guest thoughtful: {request}
> I'll take good care of her. => done
> Leave it with me. => done
-- done
guest happy: Thank you. I'll be about the dock.
end

== walkin_arrives_chatty
* The {guest_ship} bumps into the bay, and its owner is talking before the hatch is fully open.
guest happy: Hello, hello! I'm {guest}. Is that a tea nook? You have a tea nook! Lovely.
guest laughing: Sorry, I talk when I'm excited. And when I'm nervous. And on Tuesdays.
guest thoughtful: Anyway. {request}
> Tell me more about her. => more
> I'll get started. => done
-- more
guest happy: Oh, she's been everywhere. Twice round the rings, once through a moon-plum storm. I'll tell you all about it later. Probably at length.
=> done
-- done
guest happy: Wonderful. I'll be in the drum gardens, telling the misters about you.
end

== walkin_arrives_haggler

guest thoughtful: {guest}. I've seen the board. I know what this sort of work goes for.
guest: {request}
> The posted rate is fair. => fair
> We can talk about it after. => fair
-- fair
guest grumpy: Hm. We'll see what the work's worth when I see it.
end

== walkin_arrives_generous

== walkin_arrives_nervous

> Of course it is. => ok
> You're very welcome here. => ok
-- ok
guest happy: Oh good. Um. {request}

== walkin_arrives_fussy

guest: {request}

end

== walkin_arrives_sentimental
